OSCAR Docs

Open Source Copter for Academic Research (OSCAR) is a student-made, open-source drone platform designed for academic research and education. This documentation provides comprehensive guides, tutorials, and reference materials to help you get started with OSCAR and make the most of its capabilities.

About Us

Made by students,
for students.

Whether you are a student, researcher, educator, or hobbyist, OSCAR is designed to be accessible and adaptable for a wide range of applications, with open source documentation and resources to support your projects and learning journey.

The Development Team


Software Team:

The Software Team is responsible for developing the software components of the OSCAR drone customization platform. This includes the development and maintenance of the desktop application, which serves as the primary interface for users to configure with the drone. There does not currently exist free open-source drone hardware, so the intention of the desktop application is to provide a starting point for implementing custom drone implementations. Our application aims to be less complicated than existing solutions like Beta Flight, allowing users to implement their desired functionalities without the need to search for pre-existing applications. The team also works on this documentation website, ensuring that users have access to comprehensive guides and tutorials for using the platform effectively.
